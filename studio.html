1. подключение

не подключено

Чтобы сайт мог сам сохранять фото в репозиторий, нужен ключ доступа GitHub. Его создают один раз, и он хранится только в этом браузере.

  1. Открой github.com → новый ключ (fine-grained token).
  2. Token name: например, garbage studio. Expiration: 1 год (или сколько хочешь).
  3. Repository access → Only select repositories → выбери garbageofparis.
  4. Permissions → Contents → Read and write.
  5. Нажми Generate token, скопируй ключ (начинается с github_pat_) и вставь сюда:

Подключено к . Ключ хранится только в этом браузере — на другом телефоне или компьютере его нужно будет вставить ещё раз.
