# Галерея зрителей: настройка Supabase

Страница **visitors.html** («your finds» в меню) — посетители присылают свои фото.
Страница **backstage.html** (её нет в меню) — ты смотришь новые фото и решаешь:
показать на сайте или удалить.

Фото хранятся в бесплатном проекте Supabase. Настройка — один раз, минут 10.

## 1. Создать проект

1. Зайди на [supabase.com](https://supabase.com) → **Start your project** → войди через GitHub.
2. **New project**:
   - Name: `garbageofparis`
   - Database password: нажми **Generate a password** (сохрани куда-нибудь, для сайта он не нужен)
   - Region: **West EU (Paris)**
3. **Create new project** и подожди минуту-две, пока он создаётся.

## 2. Создать таблицу и хранилище

1. Слева **SQL Editor** → **New query**.
2. Открой файл [`visitor-gallery.sql`](visitor-gallery.sql), скопируй его целиком и вставь.
3. Нажми **Run**. Должно появиться «Success. No rows returned».

## 3. Закрыть регистрацию

Слева **Authentication** → **Sign In / Providers** → выключи
**Allow new users to sign up** → **Save changes**.

## 4. Создать свой вход

**Authentication** → **Users** → **Add user** → **Create new user**:
- Email: твоя почта
- Password: придумай пароль
- галочка **Auto Confirm User** — включена

Важно: владелец галереи — **самый первый** пользователь в этом списке.
Только он может одобрять и удалять фото.

## 5. Подключить сайт

Нужны два значения (оба публичные, их можно спокойно пересылать):

- **Project URL** — на главной странице проекта или в **Project Settings → Data API**,
  вида `https://abcdefgh.supabase.co`
- **Publishable key** — **Project Settings → API Keys**, начинается с `sb_publishable_`
  (если там вкладка «Legacy», подойдёт и `anon` `public` key, начинается с `eyJ`)

Вставь их в [`assets/js/visitors-config.js`](../assets/js/visitors-config.js)
(или просто пришли их Claude).

## 6. Пользоваться

- **garbageofparis.fr/backstage.html** — войти своей почтой и паролем.
  Вход запоминается в браузере.
- «показать на сайте» — фото появляется на стене в «your finds».
- «убрать со стены» — фото снова скрыто, но не удалено.
- «удалить» — насовсем.

## Что важно знать

- Пока фото не одобрено, его не видит никто — даже по прямой ссылке.
- Перед отправкой фото сжимается в браузере (до 1600 px), из файла удаляются
  геоданные и прочие метаданные.
- В очереди может ждать не больше 300 фото — защита от спама. Если очередь
  полная, посетители видят «попробуйте через несколько дней».
- Бесплатный проект Supabase засыпает, если им неделю никто не пользовался.
  Тогда придёт письмо; разбудить — кнопка **Restore project** на supabase.com.
  Пока проект спит, форма на сайте пишет, что фото не отправилось.
- Бесплатно — 1 ГБ на фото, это несколько тысяч снимков.
